😵 无法创建 WebGL 上下文

这个游戏需要 WebGL 渲染，但你的浏览器把它禁用了（或显卡驱动异常）。试试下面这些方法：

  1. Chrome / Edge：设置 → 隐私和安全 → 网站设置 → additional content settings → WebGL，改为「允许」
  2. 地址栏输入 chrome://flags/#enable-webgl，确认是 Enabled，然后重启浏览器
  3. 检查显卡驱动是否为最新；或在 设置 → 系统 → 显示 里开关一下「硬件加速」后重启浏览器
  4. 换一个浏览器试试（Chrome / Edge / Firefox / Safari 最新版）

设置好后刷新本页面即可。
